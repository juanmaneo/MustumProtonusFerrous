# MPF port mapping: reference Wine tree (repos/wine) -> port crates (crates/).
#
# One row per line, whitespace-separated:
#   <wine-subdir> <mpf-crate> <status>
#
#   wine-subdir  path under repos/wine, e.g. dlls/kernel32
#   mpf-crate    the port crate under crates/, or "-" when there is none yet
#   status       ported | partial | planned | native | todo
#                native = stays a native companion in Proton (dxvk, vkd3d-proton)
#
# Blank lines and lines starting with # are ignored.
#
# Cross-cutting crates without a single reference directory:
#   mpf-pe            PE/COFF parser (loader/ + dlls/ntdll/loader.c level)
#   mpf-winnt         winnt.h ABI structs (see the `include` row below)
#   mpf-cli           the run pipeline (loader/main.c equivalent)
#   mpf-conformance   seeded cases from dlls/*/tests
#   mpf-proton/mpf-umu  Proton's `proton` script / umu-launcher live in
#                       repos/proton and repos/umu-launcher, not in the wine tree
